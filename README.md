# Эмулятор UNIX-подобной командной оболочки

Практическая работа, вариант 9. Этап 2 — конфигурация.

## 1. Общее описание

Эмулятор этапа 1 стал настраиваемым. Параметры передаются в командной
строке, а при запуске в окно выводится отладка со всеми заданными
параметрами. Стартовый скрипт выполняет команды эмулятора и показывает
на экране и ввод, и вывод, как будто команды набирал пользователь.

Окно, заголовок `Эмулятор - [username@hostname]`, парсер и команды
`ls`, `cd` (заглушки) и `exit` сохранены.

Код находится в `src/emulator.py`, тесты — в `tests/test_emulator.py`.

## 2. Функции и настройки

Параметры командной строки:

- `--vfs ПУТЬ` — путь к физическому расположению VFS. На этом этапе
  путь только выводится в отладке, файл ещё не читается;
- `--script ПУТЬ` — путь к стартовому скрипту.

Если параметр не задан, в отладке пишется `не задан`.

Стартовый скрипт:

- комментарий — строка, которая начинается с `#` (синтаксис Python);
- пустые строки пропускаются;
- перед каждой командой печатается приглашение, затем ответ;
- ошибочная строка выводит ошибку, скрипт продолжается;
- `exit` останавливает скрипт и отключает ввод;
- отсутствующий файл скрипта выводит сообщение `Ошибка скрипта`.

Файлы этапа:

- `scripts/startup.txt` — заглушки, переменные окружения и ошибки;
- `scripts/startup_errors.txt` — только ошибочные строки и `exit`;
- `vfs/sample.json` — пример пути для параметра `--vfs`;
- `os_scripts/test_params.bat`, `os_scripts/test_params_errors.bat` —
  скрипты Windows, которые вызывают эмулятор со всеми сочетаниями
  параметров.

## 3. Сборка и тесты

Сборка не нужна, требуется Python 3 со стандартной библиотекой.

Запуск:

```bat
run.bat --vfs vfs\sample.json --script scripts\startup.txt
```

Тесты:

```bat
python -m unittest discover -s tests -v
```

Проверка параметров командной строки. Каждый вызов открывает окно;
после его закрытия выполняется следующий вызов:

```bat
os_scripts\test_params.bat
os_scripts\test_params_errors.bat
```

## 4. Примеры использования

```bat
run.bat --vfs vfs\sample.json --script scripts\startup.txt
```

```text
[debug] Путь к VFS: vfs\sample.json
[debug] Стартовый скрипт: scripts\startup.txt

korsh@COMP$ ls
ls
korsh@COMP$ ls "my dir" $USERNAME
ls: my dir korsh
korsh@COMP$ foo
Ошибка: неизвестная команда 'foo'
korsh@COMP$ exit 1
Ошибка: exit не принимает аргументы
korsh@COMP$
```

Запуск без параметров:

```text
[debug] Путь к VFS: не задан
[debug] Стартовый скрипт: не задан
```
