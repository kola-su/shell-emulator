# Эмулятор UNIX-подобной командной оболочки

Практическая работа, вариант 9. Нужно сделать эмулятор языка оболочки ОС,
работа с которым максимально похожа на командную строку UNIX-подобной ОС.

## 1. Общее описание

Это начальный коммит: в репозитории только описание и `.gitignore`.
Работа делится на пять этапов, каждый фиксируется отдельным коммитом:

1. REPL — окно и диалог с пользователем.
2. Конфигурация — параметры командной строки и стартовый скрипт.
3. VFS — виртуальная файловая система из JSON в памяти.
4. Основные команды — `ls`, `cd`, `tree`, `date`.
5. Дополнительные команды — `touch`, `cp`.

## 2. Функции и настройки

Функций и настроек пока нет: исходный код появится на этапе 1
в каталоге `src`.

## 3. Сборка и тесты

Собирать и тестировать пока нечего. Для следующих этапов нужен Python 3
со стандартной библиотекой; отдельная сборка не требуется.

## 4. Примеры использования

Примеры появятся вместе с кодом на этапе 1.
