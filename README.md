# Эмулятор UNIX-подобной командной оболочки

Практическая работа, вариант 9. Этап 5 — дополнительные команды.
Это итоговая версия работы.

## 1. Общее описание

Эмулятор языка оболочки ОС с графическим интерфейсом (Tkinter). Работа
похожа на командную строку UNIX-подобной ОС. Заголовок окна строится по
данным реальной ОС:

```text
Эмулятор - [username@hostname]
```

Виртуальная файловая система (VFS) читается из JSON-файла в память.
Команды `touch` и `cp` изменяют только память: файл на диске не
распаковывается и не изменяется.

Код находится в `src/emulator.py`, тесты — в `tests/test_emulator.py`.

## 2. Функции и настройки

### Параметры командной строки

- `--vfs ПУТЬ` — путь к физическому расположению VFS (JSON). Без него
  используется пустой корень. При ошибке чтения выводится сообщение,
  и эмулятор работает с пустым корнем.
- `--script ПУТЬ` — стартовый скрипт.

При запуске выводится отладка: оба параметра (или `не задан`), число
узлов и глубина загруженного дерева.

### Стартовый скрипт

- комментарий — строка, начинающаяся с `#` (синтаксис Python);
- пустые строки пропускаются;
- на экране видны и команда, и её результат;
- ошибочная строка выводит ошибку, скрипт продолжается;
- `exit` останавливает скрипт и отключает ввод.

### Парсер

- аргументы в двойных и одинарных кавычках;
- `$ИМЯ` и `${ИМЯ}` раскрываются по переменным окружения реальной ОС;
- в одинарных кавычках переменные не раскрываются;
- если `HOME` не задана (Windows), используется `USERPROFILE`.

### Формат VFS

- `root` — корневой каталог;
- каталог: `"type": "directory"` и список `children`;
- файл: `"type": "file"` и текст в `content`;
- двоичные данные: `"encoding": "base64"`.

Варианты в каталоге `vfs`: `minimal.json` (пустой корень), `files.json`
(несколько файлов), `deep.json` (не менее 3 уровней, файл в base64),
`broken.json` (повреждённый JSON).

### Команды

- `ls [-a] [-l] [ПУТЬ...]` — содержимое каталога; `-a` — скрытые имена
  и `.` / `..`, `-l` — тип, размер и имя.
- `cd [ПУТЬ]` — смена каталога; без пути — `/`, `cd -` — предыдущий.
- `tree [-a] [-L N] [ПУТЬ]` — дерево каталогов с ограничением глубины.
- `date [-u] [+ФОРМАТ]` — дата и время ОС; `-u` — UTC.
- `touch [-c] ФАЙЛ...` — создаёт пустые файлы в памяти. Существующее
  имя не меняется; `-c` не создаёт отсутствующий файл.
- `cp [-r] ИСТОЧНИК... ЦЕЛЬ` — копирует внутри VFS. Если цель —
  каталог, копии кладутся в него. Каталоги копируются только с `-r`.
  Копия независима от оригинала. Нельзя копировать каталог в самого
  себя и файл сам в себя.
- `exit` — выход.

Ошибки выводятся для неизвестной команды, неверного флага, отсутствующего
пути, пути-файла вместо каталога, лишних аргументов и незакрытых кавычек.

## 3. Сборка и тесты

Сборка не нужна, требуется Python 3 со стандартной библиотекой.

Запуск:

```bat
run.bat
run.bat --vfs vfs\deep.json --script scripts\startup.txt
```

```sh
sh run.sh --vfs vfs/deep.json --script scripts/startup.txt
```

Тесты:

```bat
python -m unittest discover -s tests -v
```

Скрипты Windows вызывают эмулятор со всеми сочетаниями параметров на
разных VFS. После закрытия окна выполняется следующий вызов:

```bat
os_scripts\test_minimal.bat
os_scripts\test_files.bat
os_scripts\test_deep.bat
os_scripts\test_bad_vfs.bat
```

`scripts/startup.txt` проверяет все режимы `touch` и `cp`, работу
с VFS и ошибки; `scripts/startup_errors.txt` — только ошибочные строки.
