# Эмулятор UNIX-подобной командной оболочки

Практическая работа, вариант 9. Этап 1 — REPL.

## 1. Общее описание

Минимальный прототип эмулятора с графическим интерфейсом (Tkinter).
Окно состоит из журнала сверху и поля ввода снизу. Заголовок окна
строится по данным ОС, в которой запущен эмулятор:

```text
Эмулятор - [username@hostname]
```

Команды `ls` и `cd` пока заглушки: они печатают своё имя и аргументы.
Команда `exit` завершает работу и отключает поле ввода.

Код находится в `src/emulator.py`, тесты — в `tests/test_emulator.py`.

## 2. Функции и настройки

Параметров командной строки на этом этапе нет.

Парсер команд:

- аргументы в двойных и одинарных кавычках остаются одним словом;
- `$ИМЯ` и `${ИМЯ}` раскрываются по переменным окружения реальной ОС,
  например `$HOME` или `$USERNAME`;
- в одинарных кавычках переменные не раскрываются;
- если `HOME` не задана (Windows), используется `USERPROFILE`;
- незакрытая кавычка — ошибка разбора.

Команды:

- `ls [АРГУМЕНТЫ]` — заглушка, печатает `ls` или `ls: аргументы`;
- `cd [АРГУМЕНТЫ]` — заглушка, печатает `cd` или `cd: аргументы`;
- `exit` — выход; с аргументами выдаёт ошибку.

Неизвестная команда сообщает об ошибке.

Основные функции `src/emulator.py`:

- `parse_line` — разбор строки, `expand_vars` — подстановка переменных;
- `Shell` — состояние оболочки и выполнение команд;
- `ShellGUI` — окно, вывод текста и обработка Enter.

## 3. Сборка и тесты

Сборка не нужна, требуется Python 3 со стандартной библиотекой.

Запуск:

```bat
run.bat
```

```sh
sh run.sh
```

Тесты:

```bat
python -m unittest discover -s tests -v
```

## 4. Примеры использования

```text
korsh@COMP$ ls
ls
korsh@COMP$ ls "my dir" $USERNAME
ls: my dir korsh
korsh@COMP$ cd '$HOME'
cd: $HOME
korsh@COMP$ cd $HOME
cd: C:\Users\korsh
korsh@COMP$ foo
Ошибка: неизвестная команда 'foo'
korsh@COMP$ ls "abc
Ошибка разбора команды: незакрытые кавычки
korsh@COMP$ exit 1
Ошибка: exit не принимает аргументы
korsh@COMP$ exit
Выход из эмулятора.
```
